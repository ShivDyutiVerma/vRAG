## Surprises & learnings

- Hugging Face Spaces' free tier no longer covers Docker or Gradio SDK apps — only static Spaces
  are free now. `AGENT_BUILD_SPEC.md` assumed otherwise; this is a real, dated fact worth knowing
  before defaulting to HF Spaces on future projects.
- Sarvam's realtime STT endpoint doesn't always close its side of the WebSocket promptly after
  receiving `{"event": "end"}` on silence-only audio — found this via an actual smoke test against
  the live API (not a guess), fixed with a bounded grace-period timeout rather than an indefinite
  wait. A real request path must never be able to hang forever on an idle upstream connection.
- Render can deploy directly from a *public* GitHub repo URL without installing their GitHub App
  or needing repo admin rights — useful when you're a collaborator, not the repo owner, and don't
  want to chase down OAuth app permissions mid-hackathon.
- Python's root logger defaults to `WARNING` — `logger.info()` calls are silently no-ops unless
  something calls `logging.basicConfig()`. Uvicorn configuring its own loggers can mask this,
  since you *do* see uvicorn's own request logs and might assume logging "works." A hosted deploy
  with no debugger attached is exactly where this bites hardest — always verify your own
  application logs actually appear, not just the framework's.
- A TTS API is a genuinely useful STT-testing tool: generating real speech from known text and
  feeding it back into your own STT pipeline gives a fully real, reproducible, scriptable
  end-to-end test — no physical microphone or human required, and no shortcut taken on the "must
  be real audio" rule.
- When a request-path bug only reproduces on a hosted deploy and not locally, the fastest path to
  a diagnosis is proper logging + redeploy + read the platform's log stream, not guessing. Two
  redeploy cycles here (each ~1-2 min) were far cheaper than trying to reason about it blind.
